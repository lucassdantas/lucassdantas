## 👋 Sobre mim

Sou engenheiro de software full stack no Rio de Janeiro, com **6 anos de experiência** entregando aplicações web, APIs, integrações com IA (LLMs) e e-commerces — de chatbots corporativos a sistemas críticos da área da saúde.

Gosto de resolver problemas de **arquitetura, performance e custo**: código testável, integrações confiáveis entre sistemas e otimização que aparece na fatura — seja em query SQL, seja em consumo de tokens de IA.
